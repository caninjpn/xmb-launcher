# Amazon packages this project disables on a Fire TV. One per line; blank lines and
# lines starting with # are ignored.
#
#   tools/disable.sh amazon --list tools/fire-tv-packages.txt    disable them all
#   tools/restore.sh --fire-tv                                   put them all back
#
# Nothing here is uninstalled -- `pm disable-user` hides a package from the current user,
# so every one of these can be restored exactly as it was.
#
# This list is Amazon-specific and says nothing to a generic Android TV box. On one of those,
# `adb shell pm list packages` is the place to start instead.
